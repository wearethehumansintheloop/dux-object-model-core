# 🔧 Technical Specification: Raw Output Format

## Overview

This document provides the exact technical specification for the raw output generated by the DUX Fit Template Magnet System pipeline. The pipeline extracts, processes, and outputs structured data in JSON format with complete traceability.

## 📊 Output Files Generated

The pipeline generates 3 main output files per run:

1. **`pipeline_results_TIMESTAMP.json`** - Complete raw data and processing results
2. **`one_sheets_TIMESTAMP.json`** - Generated strategic summaries
3. **`pipeline_stats_TIMESTAMP.json`** - Processing statistics

## 🔍 Traceability Features

Every object includes complete traceability:

- **`_source_filename`**: Original file where object was found
- **`_parsed_at`**: Timestamp of extraction
- **`_attracted_at`**: Timestamp when attracted by magnet (if applicable)
- **`fit_score`**: Matching confidence score (0.0-1.0)
- **`match_reasons`**: Keywords that triggered the match

This ensures full audit trail from raw source to final output.
