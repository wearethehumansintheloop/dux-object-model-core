## Template Usage Guide

### Quick Start
1. Copy the appropriate template
2. Replace placeholder content with your data
3. Update the front matter metadata
4. Add your insights and sources
5. Run through the parser to validate

### Front Matter Fields
- **title:** Main slide headline
- **layout:** Visual layout type (matrix, timeline, process, etc.)
- **component:** Specific component name (auto-detected if omitted)
- **chartType:** For data visualization slides (bar, pie, waterfall, etc.)
- **sampleSize:** For survey/demographic slides

### Content Guidelines
- Use **### headers** for main sections
- Add **- bullet points** under each section
- Include **> blockquotes** for insights and sources  
- Keep bullet points under 8 words for readability
- Always include source attribution

### Pro Tips
- **Consistent terminology:** Use the same terms throughout
- **Balanced content:** Aim for similar amounts of content per section
- **Clear insights:** Make your key takeaway obvious
- **Proper citations:** Include credible sources for all claims
- **Test early:** Validate with parser before presenting

### Common Patterns
- **Comparison slides:** Use "vs" or "compared to" in headers
- **Process slides:** Use sequential language (Phase 1, Step 2, etc.)
- **Data slides:** Include specific numbers and percentages
- **Strategic slides:** Focus on outcomes and recommendations

### Template Customization
All templates can be modified to fit your specific needs:
- Change section headers to match your content
- Adjust the number of bullet points
- Modify axis labels for matrix slides
- Update timeline phases and dates
- Customize demographic categories

Remember: The parser is designed to be flexible - these templates provide structure, but you can adapt them to your specific presentation needs.
